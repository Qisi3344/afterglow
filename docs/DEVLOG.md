1. `addDatalog` 导入源不一致导致模块加载失败 → 移入 Kit.js 统一导出
2. Player._buildModel 引用裸 `scene` → `this.scene`
3. Game 缺 `start()` 方法（入口调用）
4. **IAB 视图 rAF 节流**：渲染循环停滞 → 17ms 看门狗兜底 + 视口自愈（首帧 innerWidth=0）
5. **敌人全员出生在原点围杀玩家**（Group 位置未从 spawn 初始化）→ 构造时 copy 出生点；此前"开局即死"的元凶
6. 倒计时双实现（Game/Missions 各一套）→ 统一收敛到 MissionSystem.tick
7. IAB 无指针锁定 → 拖动转视角 + 按住射击降级；交互提示不再依赖锁定状态
8. resume() 在玩家死亡后仍可触发 → 加防护
