# 已知问题与后续建议

## 已知问题（当前版本）

1. **嵌入式视图指针锁定**：ZCode IAB 等嵌入式浏览器不支持 Pointer Lock。已实现降级：按住左键拖动转视角 + 按住左键射击。真实浏览器标签页中自动使用锁定模式，体验更佳。
2. **阴影相机跟随**：DirectionalLight 阴影范围跟随相机移动，快速长距离移动时边缘阴影可能有 1 帧迟滞。不影响可玩性。
3. **无人机避墙为简单切向滑动**：极端角落可能卡顿抖动（未观察到死锁卡死）。
4. **门滑轨 AABB 开启判定**：滑门开启动画中间态（半开）碰撞盒瞬间消失，理论上可被挤入门缝；门全开后无问题。
5. **音频上下文策略**：AudioContext 在首次点击"开始行动"时创建（浏览器手势要求）；若浏览器策略更严格（少见），首局可能无声，重开一次即可。
6. **性能**：IAB 内嵌视图下 watchdog 驱动渲染为全速（~58fps 观测）；4K 屏 + 高画质 + 撤离战满屏粒子时建议中画质。未在低配机器实测。

## 后续建议（按价值排序）

1. **小地图/目标指示箭头**：撤离战反向北跨度 170m，新手可能迷路；任务面板加方向指示即可显著改善
2. **手柄支持**：Input.js 已预留映射接口
3. **敌人类型扩展**：重型机（破盾压制）、自爆机（逼迫走位）——状态机骨架已支持
4. **更多关卡**：Zone 组件化构建流程已验证，可流水线扩展
5. **对话/字幕系统**：数据板之外加站内广播语音事件，强化叙事沉浸
6. **存档点**：中途死亡回到区域入口而非全重开（当前单局 8-15 分钟，全重开在可接受范围）
7. **WebGPU 渲染路径**：three 的 WebGPURenderer 就绪后迁移，粒子与光照上限更高
