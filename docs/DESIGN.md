# 设计说明

## 产品定位

- **名称**：残响 AFTERGLOW（副题：烛龙站打捞行动）
- **类型**：第三人称科幻探索动作（垂直切片，单关约 8~15 分钟）
- **核心卖点**：回收-重启-撤离三段式张曲线；低多边形科幻废墟美学（冷蓝 × 暖橙 × 青绿能量色）；无人机潜行/交战混合玩法
- **目标体验**：孤独感 → 探索好奇 → 收集紧张 → 撤离战肾上腺素

## 核心循环

```
进入设施 → 探索三区域回收核心（自由顺序）→ 重启信标
   ↑                                      ↓
 死亡重来（重开）← 90 秒撤离战（无人机波次追击）← 登船胜利（评级）
```

失败条件：生命归零（无人机激光）或撤离倒计时归零。
胜利条件：信标激活后 90 秒内回到打捞飞船。

## 关卡结构（z 轴向南前进，总长约 180m）

| 区域 | 职责 | 关键内容 |
| --- | --- | --- |
| A 着陆平台（z:+10~-44） | 起点、教学、撤离终点 | 打捞飞船（撤离点）、教学数据板、掩体箱堆、倒塌天线（环境叙事）、南北闸门 |
| B 研究舱段（z:-44~-108） | 探索主体、三房间分支 | 主走廊 + 温室（发光植物+核心）、实验室（隔离环+核心）、储藏室（维修站+数据板）；4 架巡逻机 |
| C 反应堆大厅（z:-108~-176） | 高潮舞台 | 中央反应堆、二层平台楼梯（核心在高台）、信标终端；激活后红色警报 + 波次生成 |

- 每个区域承担不同设计职责：教学/分支探索/垂直立体 + 撤离战
- 5 块数据板分散叙事（打捞合同、植物学家录音、安保指令、货单、值班交接），全收集计入评级
- 维修站（+50 HP 一次性）作为探索奖励与风险补偿

## 敌人 AI

状态机：`PATROL →（感知：24m 内 + 面向/6m 近距离）→ ALERT（0.5s 观察）→ ATTACK（保持 9m 环绕 + 1.3s/发激光，弹道带散布可躲避）`。受击未死直接反击。死亡爆炸掉落粒子。撤离阶段波次生成（每 7s 至多 2 架、场上上限 7），速度低于玩家冲刺（8.6 > 5.6），撤离战"能跑掉"是设计底线。

## 数值

- 玩家：HP 100 / 能量 100（冲刺 26/s，回复 14/s）/ 步行 5.2 / 冲刺 8.6 / 跳跃 8.4
- 手枪：34 dmg / 0.22s 冷却（DPS ≈ 155，三发击杀一台无人机）
- 敌人：HP 100 / 激光 12 dmg / 0.6s 受击无敌帧保护玩家
- 撤离倒计时 90s；评级 S 需 <7min + 击杀≥10 + 数据板 5/5 + 剩余>40s

## UI/UX

- 统一视觉语言：深色玻璃面板、切角（clip-path）、青/橙/红三色语义（信息/强调/危险）、扫描线覆层
- HUD：左下生命+能量、右上任务面板（阶段+进度+收集统计）、中央准星+命中标记、顶部倒计时（<20s 变红脉冲）
- 反馈：受击红晕、低血量脉动边框、交互提示、toast 通知、屏幕震动
- 完整流程：标题（开始/操作说明/设置/最佳纪录）→ HUD → 暂停 → 结算（统计+评级+新纪录）

## 音频

全程序化 WebAudio：环境层（46Hz 站体嗡鸣 + 带通风噪声）、音乐层（三角波 pad 和弦循环，撤离切换锯齿+脉冲低音）、音效层（脚步/跳跃/射击/命中/爆炸/开门/拾取琶音/警报/UI），低血量心跳。三总线（主/音乐/音效）独立音量。
